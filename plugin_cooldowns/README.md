# Cooldown Reminders

Members start a reminder for a cooldown (/cooldown daily) and get a message when it is over.

## Commands

- `/cooldown`: Reminds you when a cooldown is over
- `/cooldowns`: Shows your running cooldown reminders
- `/cooldown-stop`: Stops a cooldown reminder
