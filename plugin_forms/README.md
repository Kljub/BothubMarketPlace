# Forms

Your own questions for members; the answers arrive in a channel of your server.

- **Forms** (settings page): name, title, up to 5 questions (one per line;
  `(long)` for a big text box, `(optional)` for an optional one), the answers
  channel, panel text and button text.
- **Open:** `/form <name>`, or the button that `/form-panel <name>` posts.
- **Answers:** an embed with every question and answer in the answers channel;
  with review on, Accept / Decline buttons (reviewer roles, optional ping
  role). Accept can give a role.
- **Once:** one open answer per member until it is decided.

The bot needs Manage Roles (and its role above the role it gives) for the
role on accept.
